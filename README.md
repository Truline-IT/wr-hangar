Static front door for www.gragg.life, served by GitHub Pages.

- `/` landing page
- `/adams-hangar/` redirects to the Moody.Adam Hangar artifact on claude.ai
- `/adams-hanger/` catches the common misspelling and forwards to `/adams-hangar/`
- `CNAME` sets the custom domain

The hangar itself is a Claude artifact and is not hosted here. This repo only holds the door.
